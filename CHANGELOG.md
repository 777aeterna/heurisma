# Changelog

All notable changes to **Heurisma** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-20

### Added
- Core scientific-method agent skill (`skills/heurisma/SKILL.md`) with Pre-Search Gate, 6-stage cognitive workflow, 3 adaptive depth levels, 7-section Output Contract, and anti-pressure rationalization defenses.
- Modular domain and methodology references (`references/disciplines.md`, `data-protocol.md`, `adversarial-review.md`, `scientific-writing.md`).
- Zero-dependency Python structural & epistemic validator (`skills/heurisma/scripts/validate_report.py`) with unit test suite (`tests/test_validate_report.py`).
- RED–GREEN–REFACTOR skill evaluation suite (`evals/scenarios/01..06`, `evals/baselines/baseline-report.md`, `evals/results/green-eval-report.md`).
- Real showcase examples (`examples/level1-brief-example.md`, `examples/level2-data-study-example.md`, `examples/scripts/analyze_example.py`).
- Official minimalist geometric emblem (`assets/logo.png`), GitHub Actions CI (`validate-skill.yml`), cross-runtime installation README, and community templates.
