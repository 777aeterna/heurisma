# Appendix — reproduction

Run from the report folder (`emergence-in-physics-v102/`):

```bash
python3 -B appendix/analysis.py
```

`analysis.py` (Python ≥ 3.9, standard library only, 4 worker processes, about 90 s) writes `appendix/output.txt`,
`appendix/numbers.json` and `../charts.json` directly. Every random stream is seeded from its task label, so the
outputs are bit-for-bit reproducible.

Data provenance: no external numerical dataset is used; all numbers are generated by the simulation. There is
no `fetch_data.py` because nothing is downloaded for the analysis. The literature in `sources.csv` was retrieved
in this run with the Heurisma paper connector (`papers.py search` / `lookup` / `cite --fulltext`); its raw
responses are cached under `data/papers/raw/`, open-access full texts under `data/papers/`, and every request is
logged in `download_log.csv`, `search_log.csv` and `data_attempts.csv`. Nothing was copied from `datos/` or from
an earlier run.
